数组与链表

数据结构是组织和存取数据的方式。选择结构时，先看需要频繁执行什么操作：按下标访问、在中间插删，还是按一定顺序取出。

传统数组通常存放同类型元素，长度固定；Python的list长度可变、可以混合类型。Python列表内部连续存放的是对象引用，对象本身不一定连续。

链表的每个结点保存数据和指向下一个结点的引用，结点不必连续存放。它不必移动后面的元素，但按位置查找时需要从头沿引用查找。

操作 数组 / Python list 单向链表
按下标访问 \(O(1)\) \(O(n)\)
头部插入 \(O(n)\)，后续元素移动 \(O(1)\)
已知位置插入、删除 最坏\(O(n)\) 改链接\(O(1)\)

链表删除需要已经持有待删结点的前驱结点；若先按值或下标寻找位置，查找仍需\(O(n)\)。链表结点分散，也可能不如连续存储有利于缓存。

Python有array等专门的数组工具；日常通用序列通常使用list。

栈：后进先出

栈（Stack）遵循LIFO (Last in First Out)：最后入栈的元素最先出栈。主要操作是push入栈、pop出栈、peek查看栈顶。撤销操作和函数调用栈都符合这一顺序。

strokes = []
strokes.append("圆形")
strokes.append("直线")
strokes.append("矩形")
strokes.pop()          # "矩形"
strokes[-1]            # "直线"，查看但不删除

用list尾部append和pop()实现栈，两者均摊\(O(1)\)；空列表执行pop()或stack[-1]会抛出IndexError。

括号匹配

右括号必须与最近一个尚未匹配的左括号配对，所以使用栈。下面约定输入只含六种括号：

def is_valid(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        else:
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
    return not stack

{[()]}依次压左括号入栈，再依次匹配出栈，最后栈空，返回True。要检查三种错误：右括号到来时栈空、栈顶类型不匹配、读完后栈里仍有左括号。not stack or ...利用逻辑短路，先避免访问空栈。

每个字符最多入栈和出栈一次，时间\(O(n)\)；最坏情况下栈保存\(n\)个左括号，空间\(O(n)\)。

队列：先进先出

队列（Queue）遵循FIFO (First in First Out)：队尾入队，队首出队。打印任务、餐厅订单和广度优先搜索(BFS)都要求先来先处理。

from collections import deque

orders = deque()
orders.append("A")         # 队尾入队
orders.append("B")
first = orders.popleft()  # 队头出队，得到 "A"

list.pop(0)虽然也能取队头，但删除后其余引用要前移，单次\(O(n)\)；连续取空\(n\)个元素总共需要\(O(n^2)\)。deque.popleft()从左端取出，单次\(O(1)\)，连续取空为\(O(n)\)。

需求 Python写法 顺序
栈 list.append() / list.pop() LIFO
队列 deque.append() / deque.popleft() FIFO
两端进出 deque的左右端方法 按需求决定

deque常用操作

deque是双端队列，从collections导入。两端追加与弹出通常都是\(O(1)\)；它适合队列，但中间位置的随机访问是\(O(n)\)，不能代替列表频繁按下标访问。

写法 作用 返回值 / 注意
deque(iterable) 用可迭代对象初始化 新deque
append(x) / appendleft(x) 右端 / 左端加入 None
pop() / popleft() 右端 / 左端移除并返回 空队列抛IndexError
extend(xs) / extendleft(xs) 逐个加入右端 / 左端 extendleft会使加入部分的顺序反转
rotate(k) 循环移动 正数向右、负数向左；原地修改
clear() 清空 None
d[0] / d[-1] 查看两端 不删除；空队列不能取下标 
from collections import deque

d = deque([1, 2, 3])
d.extendleft([4, 5])  # deque([5, 4, 1, 2, 3])
d.rotate(1)           # deque([3, 5, 4, 1, 2])

recent = deque(maxlen=3)
recent.extend([1, 2, 3, 4])  # deque([2, 3, 4])

设置maxlen后，append或appendleft在已满时会从另一端丢掉元素；这是有界缓存的行为，使用前要确认是否允许丢失旧数据。

栈与队列的检查

情况 要检查什么
右括号先出现 取栈顶前先判空
读完还有左括号 最后返回not stack，不能直接返回True
空队列出队 先用if d:判断，或处理IndexError
用list.pop(0)做长队列 改用deque.popleft()
保存回溯路径 需要快照时用path[:]；直接保存path会共享同一列表

Git与GitHub

Git是本地版本控制工具；GitHub可以托管远程Git仓库。一次commit记录暂存区的快照，push把本地提交上传到远程。

工作区 ── git add ──> 暂存区 ── git commit ──> 本地仓库 ── git push ──> 远程仓库
命令 作用
git init 在当前目录初始化仓库
git status 查看工作区和暂存区状态
git add README.md 把文件当前内容加入暂存区
git commit -m "说明" 提交暂存区快照
git log --oneline 简要查看提交历史
git remote -v 查看远程地址
git push -u origin main 推送分支并设置上游

第一次提交与推送

在项目目录中写好README.md，记录组号、成员和日期：

git init
git status
git add README.md
git commit -m "W8 研讨：第一次提交"
git log --oneline

GitHub上新建空仓库后，将示例地址替换成自己的HTTPS地址：

git remote add origin https://github.com/用户名/仓库名.git
git branch -M main
git push -u origin main

若本地已有README.md，新建远程仓库时不预先创建同名文件，可减少首次推送时的历史冲突。推送完成后检查远程页面是否显示文件。

.gitignore与常见问题

在仓库根目录创建.gitignore，例如：

__pycache__/
*.pyc
.vscode/
.DS_Store

.gitignore只影响尚未被跟踪的文件；已跟踪的缓存需要先从Git索引中移除，规则才会生效。提交前用git status检查，避免加入缓存、密钥和密码。

现象 检查
nothing to commit 用git status确认是否有改动、是否已经add
remote origin already exists 用git remote -v查看已有地址
push认证失败 检查远程地址与GitHub认证方式
.gitignore不起作用 检查文件是否已经被跟踪

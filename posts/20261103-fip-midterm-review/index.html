IPO环节

IPO=输入（input），处理（process），输出（output） 这是一般的程序具备的三个基本环节。

输出

函数print()

  • print函数将字符串参数打印在终端中作为输出
  • 多个字符串参数使用逗号连接，默认使用空格连接
  • 可选参数end缺省为'\n'即换行符，也即print()函数每次打印完内容会自动换行，可以通过设置end=' '或者其他字符来改变末尾的输出

输入

函数input()

  • 读入用户在终端中输入的一行作为函数的返回结果
  • 用户的键盘输入在按下[Enter]之后才会被函数读取
  • input()函数的返回值是一个字符串，即使输入的是数字
  • 可以向input()函数传递一个字符串参数作为终端中输入的提示词
number = int(input("Enter your favorite number:"))
# 终端中显示效果如下
# Enter your favorite number:

变量

变量是值的名字，在Python中使用=进行赋值。先算右边，再让左边的名字指向这个值；赋值不是数学上的相等关系。

变量命名规则

  • 必须以字母、下划线开头，后面可以跟任意数量的字母，数字，下划线
  • 变量名区分大小写
  • 变量名不能含有空格
  • 变量名不能以数字开头
  • 变量名不能与Python中的关键字（keywords）重复
  • 变量名不要与内置函数名重复；语法上允许，但会覆盖原来的名字，如sum = 0后不能直接调用sum()

数据类型

Python中数据类型有很多，之后会进行介绍，这里先讨论基本的三类

函数type()

  • 将一个变量作为参数传递给type()函数，会返回变量储存值的数据类型，基本的有：
    • int：整型
    • float：浮点型
    • str：字符串 数据类型间的差异之后再进行介绍

数据类型转换函数

  • int()函数：把可以转变的字符串，或浮点型转换为整型，对于浮点数来说，这进行的是向零取整，即砍掉小数部分
  • float()函数：把可以转变的字符串，或整型转换为浮点型
  • str()函数：把浮点型，整型转换为一个字符串

循环语句

while循环

典型计算

时间差

先统一成分钟，再用//和%拆回小时、分钟。若题目允许跨过午夜，负差值加一天。

diff = h2 * 60 + m2 - (h1 * 60 + m1)
if diff < 0:
    diff += 24 * 60
print(diff // 60, diff % 60)

哨兵与平均数

total, count = 0, 0
while True:
    x = int(input())
    if x == -1:
        break
    total += x
    count += 1
if count > 0:
    print(total / count)
  • 初始化放在循环外；哨兵不参与计算，先判断再累加
  • 没有有效数据时不能直接除以count

一行读入多个数

h, m = map(int, input().split())
  • input()读一整行，split()按空白拆开，map(int, ...)逐项转为整数
  • 左边变量个数要与输入段数一致，浮点数用map(float, ...)

格式化输出

print(1, 2, sep='-', end='!')  # 1-2!，不换行
print(f'{3.5:.2f}')           # 3.50
  • sep控制参数之间的分隔，默认空格；end控制末尾，默认换行
  • :.2f保留两位小数，格式化字符串前要加f
  • print()负责输出，返回值是None

运算注意

  • /得到浮点商，//向下取整；int()是向零截断，两者对负数可能不同
  • int('3.5')报错；int(float('3.5'))得到3
  • 2 ** 3 ** 2是2 ** (3 ** 2)；-2 ** 2是-(2 ** 2)
  • '1' + '2'得到'12'；'2' * 3得到'222'

文件与终端

  • .py是Python源文件；改代码后先保存再运行
  • 相对路径从当前工作目录出发，绝对路径从磁盘或根目录出发
  • cd切换目录，dir或ls查看文件，python 文件名.py运行程序

W2 枚举与减治

课程材料：26FIP2 枚举与减治.pdf

分支

if condition:
    ...
else:
    ...
  • 条件成立执行if，否则执行else，两者只走一个
  • else与对应的if对齐；多个独立if则可能都执行

逻辑运算

运算符 含义 短路规则
and 都成立 左边为假，不算右边
or 至少一个成立 左边为真，不算右边
not 取反 优先级高于and和or

0、空字符串、空容器、None为假。and、or返回选中的操作数，不一定是布尔值，如0 or 7得到7。

for与range

for i in range(2, 6):
    print(i)  # 依次输出2、3、4、5
写法 产生的整数
range(4) 0、1、2、3
range(2, 5) 2、3、4
range(5, 0, -2) 5、3、1
  • 左闭右开，不包含终点；步长不能为0，参数须为整数
  • range(5, 2)为空，不执行循环体
  • 次数已知用for，直到条件满足或读到哨兵用while

break、continue与循环else

  • break退出当前循环；continue跳过本轮剩余语句，进入下一轮
  • 循环正常结束时执行else；通过break退出则不执行
  • 空循环也会执行else；continue不会取消else

枚举(Enumeration)

逐一检查有限的候选解，不遗漏、不重复。最坏情况要考虑全部候选。

素数判断

若\(n\)有非平凡因子，至少一个不大于\(\sqrt n\)，所以只需检查到平方根。

def is_prime(n):
    if n < 2:
        return False
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True
  • 0、1不是素数；2是素数
  • 平方根边界要包含，如49须检查到7
  • 朴素检查到\(n-1\)为\(O(n)\)，平方根界为\(O(\sqrt n)\)

减治(Decrease and Conquer)

每一步缩小问题规模，直到能直接求解。

辗转相除法

\[ \gcd(a,b)=\gcd(b,a\bmod b) \]

while b != 0:
    a, b = b, a % b
print(a)
  • 同步赋值先计算右边所有旧值，再赋给左边
  • 不能改成a = b后再b = a % b，后一句的a已经变了
  • 例如(48, 18) → (18, 12) → (12, 6) → (6, 0)，最大公约数为6
  • 若求最小公倍数，先保存原来的乘积，再除以最大公约数（此处考虑正整数）

二分法求根

连续函数在端点异号的区间内至少有一个根。每次取中点，保留仍包围根的一半。

# 已知f连续，f(left) < 0 < f(right)
while right - left > eps:
    mid = (left + right) / 2
    if f(mid) < 0:
        left = mid
    else:
        right = mid
root = (left + right) / 2
  • 实数中点用/；每次区间宽度减半
  • 端点同号只表示不能用异号条件保证有根，不能断言无根
  • 区间宽度、残差abs(f(x))、相邻估计值差是不同的终止标准，看题目要求
  • 中点误差不超过最终区间宽度的一半；浮点数一般不用==判断近似相等

math模块

import math
math.sqrt(9)   # 3.0
math.sin(math.pi / 2)  # 三角函数参数用弧度

sqrt()返回浮点数，作为range上界时要转为整数并检查右开边界。eval()把字符串当表达式执行，不适合直接处理不可信输入；函数公式优先用def或lambda。

PTA W2 · 2D02《零钱店铺》

给定金额\(x\)（分），用\(1\)分、\(2\)分、\(5\)分硬币凑出，输出所有方案的三种硬币数量。数量允许为\(0\)，按\(1\)分枚数最外层、\(5\)分枚数最内层的循环顺序输出。例如\(x=5\)时，依次输出0 0 1、1 2 0、3 1 0、5 0 0。

def coin_plans(x):
    plans = []
    for a in range(x + 1):
        for b in range(x // 2 + 1):
            for c in range(x // 5 + 1):
                if a + 2 * b + 5 * c == x:
                    plans.append((a, b, c))
    return plans

这是按题面范围枚举的函数版，调用方逐行打印方案。可缩小范围提高效率，但不能改变要求的输出次序。

迭代

反复执行同一个规则，前一步的结果作为下一步的输入，逐渐得到足够好的近似解。

牛顿迭代法(Newton-Raphson Method)

用当前点的切线与横轴交点作为下一次估计。

\[ x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)} \]

求\(a\)的平方根，令\(f(x)=x^2-a\)，得到：

\[ x_{k+1}=\frac{x_k+a/x_k}{2} \]

def root(a, eps):
    if a == 0:
        return 0.0
    x = max(1.0, a)
    while abs(x * x - a) >= eps:
        x = (x + a / x) / 2
    return x
  • 此函数假设a >= 0、eps > 0；a=0单独处理
  • 牛顿法需要导数，单根附近二阶收敛，但初值不合适可能不收敛
  • 分母不能为0；a / x不能写成a // x

弦截法(Secant Method)

用最近两个点的割线代替切线，不需要导数。

\[ x_{k+1}=x_k-f(x_k)\frac{x_k-x_{k-1}}{f(x_k)-f(x_{k-1})} \]

def secant(f, prev, curr, eps):
    for _ in range(100):
        fp, fc = f(prev), f(curr)
        if abs(fc) < eps:
            return curr
        if abs(fc - fp) < 1e-12:
            return None
        nxt = curr - fc * (curr - prev) / (fc - fp)
        prev, curr = curr, nxt
    return None
  • 需要两个初值，不要求端点异号；也可能不收敛
  • 先检查当前点是否已满足精度，再检查分母
  • f是可调用的函数，取值写f(x)，不能写eval(x)
  • 对\(f(x)=x^2-2\)，初值1、2，下一点为\(4/3\)

蒙特卡洛方法

在单位正方形随机取\(n\)个点，其中\(m\)个在四分之一单位圆内，估算\(\pi\approx4m/n\)。

import random
random.seed(42)
hits = 0
for _ in range(n):
    x, y = random.random(), random.random()
    if x * x + y * y <= 1:
        hits += 1
print(4 * hits / n)
  • random.random()范围是[0, 1)；seed用于复现，不保证结果更准确
  • n须大于0；样本更多通常统计误差更小，不保证每一次结果都更准
  • 典型误差量级为\(O(1/\sqrt n)\)，误差缩小10倍通常需约100倍样本
  • 布丰投针在针长\(L\le d\)时，相交概率\(P=2L/(\pi d)\)

大数加法

字符串逐位模拟竖式，从个位算起：本位为total % 10，进位为total // 10。

def big_add(a, b):
    result, carry, i = '', 0, 1
    while i <= max(len(a), len(b)) or carry:
        da = int(a[-i]) if i <= len(a) else 0
        db = int(b[-i]) if i <= len(b) else 0
        total = da + db + carry
        result = str(total % 10) + result
        carry = total // 10
        i += 1
    return result
  • 假设输入为非空的非负整数字符串，短数缺位补0
  • 有最高位进位时须多算一轮；新数位放在结果左边
  • Python的int本身支持任意精度，逐位模拟是为了学习算法
  • 字符串不可变；x ** 2并非用泰勒展开实现，不能据此判断效率

多分支if-elif-else

语句示例

if condition1:
    statement1
elif condition2:
    statement2
else:
    statement_default

作为一整个语句块，执行的顺序是从上到下，在第一个为真的分支执行过后跳过后续所有分支。 需要注意多分支语句与多个if语句判断的区别，多个独立的if语句会执行多次判断，而非互斥的分档。 条件顺序也是优先级，分档时一般从严到宽，如先判断>= 90，再判断>= 60，否则高分会提前落入低档。

条件表达式

形式为

最值查找

先用第一个值作初值，再逐个比较更新；不要随意用0作最大值初值，否则全为负数时出错。

def max_index(lst):
    if not lst:
        return -1
    idx = 0
    for i in range(1, len(lst)):
        if lst[i] > lst[idx]:
            idx = i
    return idx

>保留第一次最大值位置，>=保留最后一次。min、max只返回值；空序列没有默认值时会报错。

线性查找

def linear_search(lst, target):
    for i in range(len(lst)):
        if lst[i] == target:
            return i
    return -1
  • 无序表也能查，返回第一次匹配的位置
  • 最坏比较\(n\)次，时间\(O(n)\)；额外空间\(O(1)\)
  • -1表示没找到，不能直接拿它索引列表，否则会读到最后一项

二分查找

def binary_search(lst, target):
    left, right = 0, len(lst) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if lst[mid] == target:
            return mid
        elif lst[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
  • 前提是按查找所用的规则升序排列；按时间排列不代表按温度值升序
  • 闭区间[left, right]，相等时还有一个候选，所以用<=
  • 每次排除中点，用mid + 1或mid - 1；空表直接返回-1
  • 定长整数中left + right可能溢出，改用区间差算中点；Python整数通常无此问题
  • 重复值返回某一次匹配，不保证首次；要首次则记录答案后继续向左查

手推边界

对[2, 5]查5：先left=0, right=1, mid=0，再left=1, right=1, mid=1，返回1。若用left < right，会漏掉最后一步。

enumerate：同时取得编号和元素

enumerate(iterable, start=0)依次产生(编号, 元素)，循环中用两个变量拆开。默认从\(0\)编号；start只改变编号的起点，不会跳过元素或改变原序列的下标。

names = ['甲', '乙', '丙']
print(list(enumerate(names)))           # [(0, '甲'), (1, '乙'), (2, '丙')]
print(list(enumerate(names, start=1)))  # [(1, '甲'), (2, '乙'), (3, '丙')]

只需要值时用for x in names；同时需要位置和值时用for i, x in enumerate(names)。若使用start=1，得到的是从\(1\)开始的编号，不能直接拿它当原列表下标。

zip：把多个序列按位置配对

zip(a, b, ...)依次取各序列的第一个、第二个……元素，组成元组。默认任何一边耗尽就结束，所以结果长度等于最短输入的长度；它不会补齐较短的一边。

names = ['甲', '乙', '丙']
scores = [90, 85]
print(list(zip(names, scores)))  # [('甲', 90), ('乙', 85)]
for name, score in zip(names, scores):
    print(name, score)

enumerate与zip返回的都是迭代器，按需产生结果；直接print(zip(...))不会打印配对内容，要看完整结果可先转成list。同一个迭代器被取完后，再遍历不会从头开始，需要重新创建。

any与all：检查一组条件

两者接收可迭代对象，按每个元素的真值判断，不要求元素本身是True或False。数值\(0\)、空字符串、空容器和None为假，其余常见非空值为真。

函数 返回True的条件 短路时机 空输入
any(xs) 至少一个元素为真 遇到第一个真值就停止 False
all(xs) 所有元素都为真 遇到第一个假值就停止 True 
print(any([0, '', 3]))             # True
print(all([1, 'x', []]))           # False
print(any(x < 0 for x in [2, -1])) # True，是否存在负数
print(all(x >= 0 for x in [2, 0])) # True，是否全部非负
print(any([]), all([]))           # False True

空输入里找不到一个真值，所以any([])为False；也找不到违反“全部为真”的反例，所以all([])为True。如果题目要求“列表非空且所有元素满足条件”，要写bool(xs) and all(条件 for x in xs)。

短路只停止继续取元素：any(f(x) for x in xs)会按需调用f；若写成any([f(x) for x in xs])，列表中的函数调用在进入any前就已全部完成。

课程材料：26FIP5 哈希.pdf

回顾查找算法

遍历查找

如果每次遍历查找，时间复杂度是\(O(n)\)。

二分查找

在排序基础上每次二分查找时间复杂度是\(O(\log n)\)。

有没有更快的方法？ 如果能通过键算出槽位，就可以先定位，再检查该槽位的键。

哈希的核心思想

哈希把“键”输入哈希函数，得到槽位索引，再检查该槽位是否对应目标键。

哈希的工作流程
键 -> 哈希函数 -> 槽位 -> 检查键 -> 取值

哈希先算槽位，再检查冲突位置上的键。查找平均\(O(1)\)；极端冲突时可能退化为\(O(n)\)，计算哈希值本身也有成本。

哈希的设计方法

大小选择

教学中的取模哈希常选素数作为表长，减少某些规律性输入的聚集，但不保证没有冲突。Python的dict不要求表长为素数。

实际案例

假设我们有传感器ID：

S-042, S-117, S-205, S-333, S-055

设计一个大小为13的哈希表，函数规则为提取数字部分再对表的大小取模

def hash_func(key, table_size):
    num = int(key.split("-")[1])
    return num % table_size

但是S-042和S-055会算出同一个值，这就是哈希冲突。 冲突是不可避免的，根据Pigeonhole Principle，键的空间比表的空间大的时候冲突必然会发生。所以关键在于处理冲突，而非避免冲突。

冲突处理

开链法 Separate Chaining

相当于每一个槽位储存的是一个列表，而不是单一的值，冲突发生后，就把新元素加到对应位置的链表里，然后在查找时，再在小的列表里做遍历查找。

初始化哈希表
# 遍历添加
hash_table = []
for _ in range(table_size):
    hash_table.append([])
# 列表推导式
hash_table = [[] for _ in range(table_size)]

上述两种方法都为每个槽位新建列表。下面的重复操作会使所有槽位指向同一个内层列表：

table = [[]] * table_size  # 不适合开链法
构建表
table_size = 13
hash_table = [[] for _ in range(table_size)]
collision_count = 0

def insert(key, value):
    global collision_count
    idx = hash_func(key, table_size)
    for i, (old_key, _) in enumerate(hash_table[idx]):
        if old_key == key:
            hash_table[idx][i] = (key, value)  # 同键更新
            return
    if hash_table[idx]:
        collision_count += 1
    hash_table[idx].append((key, value))

这里用global展示作用域；日常函数更适合把表作为参数传入，计数通过返回值传出。

查找流程
def hash_lookup(hash_table, key, table_size):
    idx = hash_func(key, table_size)
    slot = hash_table[idx]
    for k, v in slot:
        if k == key:
            return v
    return None

关键分析： - 理想状态下（无冲突），查找只需要\(O(1)\) - 冲突的时候需要进行线性查找，但是如果哈希函数设计的好，表的大小合适，每个槽位的列表都很短，仍然近似于\(O(1)\) - 极端情况（所有键都冲突）哈希表退化为链表，查找退化为\(O(n)\)

线性探测 Linear Probing

线性探测的思路就是如果当前槽位冲突了，就往后找到下一个空槽位储存。

def insert_probe(hash_table, key, value, table_size):
    idx = hash_func(key, table_size)
    for _ in range(table_size):
        if hash_table[idx] is None:
            hash_table[idx] = (key, value)
            return
        if hash_table[idx][0] == key:
            hash_table[idx] = (key, value)
            return
        idx = (idx + 1) % table_size
    raise ValueError('哈希表已满')

本例须先用[None] * table_size建表。同键更新不会无限探测；表满时明确报错。查找也必须沿同样路径探测。删除时直接设为None会截断后续键的查找，需要删除标记。

冲突处理策略的比较

维度 开链法 线性探测
储存结构 每个槽位是列表 每个槽位是元素或空
冲突处理 追加到列表 向后找空位
空间利用 需要额外储存链表/列表 紧凑，无需额外指针
删除难度 容易 困难
Python dict 不采用此法 采用更复杂的开放寻址策略

Python中dict类型采用更复杂的开放寻址策略（Open Addressing）。

  • Python不需要声明变量，第一次赋值就声明了变量
  • 在函数内

字符串哈希

ord(ch)取得字符的Unicode码位，chr(n)做反向转换。简单相加再取模容易让换位词冲突；可让字符顺序参与计算：

def string_hash(key, table_size):
    h = 0
    for ch in key:
        h = (h * 31 + ord(ch)) % table_size
    return h

这仍可能冲突，也不是Python内置hash()的具体实现。内置hash()对字符串的结果在不同进程中可能不同，不适合保存跨运行的固定槽位。

两数之和

两数之和可边遍历边存已见过的值及其下标。先查补数，再存当前数，避免同一个位置使用两次：

def two_sum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return seen[target - x], i
        seen[x] = i
    return None

print(two_sum([2, 11, 7, 15], 9))  # (0, 2)

平均时间\(O(n)\)、额外空间\(O(n)\)。课件把“需要的补数”存成键，上面改为存“已经见过的数”，两种写法都要保证先查后存。

递归

函数调用自身，把原问题化为更小的同类问题。写法：明确出口 → 缩小规模 → 组合子问题结果。

四原则 要点
Base Case 最小规模直接返回
Make Progress 每次调用都向出口推进
Always Believe 假设子问题正确，只考虑当前层
Compound Interest 避免重复计算同一状态，必要时记忆化

汉诺塔

将\(n\)个盘从source移到target，借助aux；每次移动一个盘，大盘不能放在小盘上。

  1. 将上面\(n-1\)个盘从source移到aux。
  2. 将最大盘从source移到target。
  3. 将\(n-1\)个盘从aux移到target。
  4. \(n=0\)时直接返回。
def hanoi(n, source, target, aux):
    if n == 0:
        return
    hanoi(n - 1, source, aux, target)
    print(f"Move disk {n} from {source} to {target}")
    hanoi(n - 1, aux, target, source)

当\(n=3\)时，调用树如下：

hanoi(3, A, C, B) 
├── hanoi(2, A, B, C) 
│   ├── hanoi(1, A, C, B) 
│   │    ├── hanoi(0, A, B, C) → 返回 
│   │    ├── move 1 from A to C 
│   │    └── hanoi(0, B, A, C) → 返回 
│   ├── move 2 from A to B 
│   └── hanoi(1, C, B, A) ... 
├── move 3 from A to C 
└── hanoi(2, B, C, A) ...

递进、回归与调用栈

  • 递进：不断调用更小的子问题，直到Base Case。
  • 回归：子调用返回，当前层继续执行并返回结果。
  • 调用栈遵循LIFO：后调用的先返回；各层保留自己的参数、局部变量和执行位置。
  • 没有出口，或无法到达出口，会不断增加调用深度，最终触发RecursionError。

阶乘：线性递归

\[ n!=\begin{cases} 1, & n=0\\ n\times(n-1)!, & n>0 \end{cases} \]

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

factorial(4)先逐层调用到factorial(0)，再依次算出1!、2!、3!、4!。每层只产生一个子调用：时间\(O(n)\)，调用栈\(O(n)\)。汉诺塔则每层产生两次规模为\(n-1\)的调用，移动次数满足\(T(n)=2T(n-1)+1=2^n-1\)，调用栈深度为\(O(n)\)。

斐波那契数列问题：合成效益法则的重要性

考虑最经典的斐波那契数列问题

递归定义斐波那契数列

\[ f(n)=\begin{cases} n, & n=0\text{ 或 }1\\ f(n-1)+f(n-2), & n>1 \end{cases} \]

代码实现

def fib(n):
    if n == 0 or n == 1:
        return n
    return fib(n -1) + fib(n - 2)

调用树

fib(5)
├── fib(4) 
│   ├── fib(3) 
│   │   ├── fib(2) 
│   │   │   ├── fib(1) 
│   │   │   └── fib(0)
│   │   └── fib(1)
│   └── fib(2)
│       ├── fib(1)
│       └── fib(0)
└── fib(3)
    ├── fib(2) 
    │   ├── fib(1)
    │   └── fib(0)

这是一个树状递归，算法的效率事实上远低于一般的迭代算法。为什么？ 因为这个算法违反了之前所说的合成效益法则：fib(2)被计算了3次，fib(1)被计算了5次，也就是说我们重复计算了多次同一个子问题 ，这样会导致算法的效率极其低下。

复杂度分析

  • 每次调用产生2个子调用，递归树深度为\(n\)
  • 时间复杂度为\(O(2^n)\)
  • 调用栈深度为\(O(n)\)

斐波那契数列的记忆化优化递归算法

既然重复计算会导致算法效率极大下降，那我们不妨记录已经算出过的调用值，因为我们几乎肯定在数据规模增大时，前面算出的数值一定会被后续调用层调用，减少重复计算的收益远高于储存计算结果的开销。

def fib_memo(n, memo=None):
    if memo is None:
        memo = {}
    if n in memo:
        return memo[n]
    if n == 0 or n == 1:
        result = n
    else:
        result = fib_memo(n - 1, memo) + fib_memo(n - 2, memo)
    memo[n] = result
    return result

通过记忆化，每个不同的\(n\)只计算一次，时间和缓存空间都是\(O(n)\)；递归调用栈仍是\(O(n)\)。

memo=None与memo={}的区别：默认参数只在函数定义时求值一次。写成memo=None，每次不传memo的顶层调用都会新建字典；递归时显式传入memo，同一次计算仍共用缓存。写成memo={}也能正确计算斐波那契数，但多次不传memo的顶层调用会共用同一个字典，缓存会一直保留。需要每次独立计算时用None；有意跨调用复用缓存时才考虑{}。

@lru_cache：函数进、函数出

手写的memo可以换成库：

from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n == 0 or n == 1:
        return n
    return fib(n - 1) + fib(n - 2)

@是装饰器：输入一个函数，返回一个增强后的函数（带有cache）。内部是函数进、函数出，也即高阶函数。缓存的键来自函数参数，参数必须可哈希；maxsize=None表示不限制缓存条目数。fib.cache_info()可查看命中情况，需要重新统计或清空缓存时调用fib.cache_clear()

Euclid算法

辗转相除法也可以写成递归函数的形式，这里直接给出代码形式：

def gcd(x, y):
    if y == 0:
        return x
    return gcd(y, x % y)

尾递归(tail recursion)

  • 当递进结束时，不对递进调用返回的值再做任何计算就直接返回的是尾递归：
    • return gcd(y, x % y)
  • 尾调用返回后没有待完成的计算，但在Python中它仍然会占用调用栈；Python不会自动把它优化成循环

尾递归和循环的转化

def gcd(x, y):
    while y != 0:
        x, y = y, x % y
    return x

一般递归与循环的转化（递归变迭代）

# 引入结果变量p，改造为尾递归
def f(n, p=1):
    if n == 0 or n == 1:
        return p
    else:
        return f(n - 1, p * n)

# 把尾递归改写为循环 
def f(n, p=1):
    while n != 0 and n != 1:
        n, p = n - 1, n * p
    return p

把（线性）递归往往可以改写为循环，而这往往可以提高程序运行的性能。换言之，递归可以作为算法思考的方法，具体的实现方法可以通过改写为循环实现。

Quick Check 3

已知first(xs)返回第一个元素，butfirst(xs)返回去掉首元素后的剩余列表，isempty(xs)判断列表是否为空。不使用循环，实现count、reverse、find、iterate和讲义中的accumarate（累计）。以下默认xs支持构造空列表、单元素列表以及列表拼接。

def count(xs):
    if isempty(xs):
        return 0
    return 1 + count(butfirst(xs))

def reverse(xs):
    if isempty(xs):
        return []
    return reverse(butfirst(xs)) + [first(xs)]

def find(xs, element):
    if isempty(xs):
        return False
    return first(xs) == element or find(butfirst(xs), element)

def iterate(xs, f):
    if isempty(xs):
        return
    f(first(xs))
    iterate(butfirst(xs), f)

def accumarate(xs, f, value):
    if isempty(xs):
        return value
    return accumarate(butfirst(xs), f, f(first(xs), value))

五题的Base Case都是空列表：数量为0、逆序为空列表、查找为False、遍历直接结束、累计则返回当前value；Progress都是递归处理butfirst(xs)。reverse必须把当前首元素放在剩余列表逆序结果的末尾；find借助or短路，找到后不再继续查；iterate先调用f再递归，保持原有顺序；accumarate先算f(first(xs), value)，再把新值交给下一层，所以f的两个参数顺序不能颠倒。

递归四基础

基础 含义 缺了会怎样
Base Case 最小规模直接返回，不再递归 无限递归，最终RecursionError
Make Progress 每次调用都向Base Case靠近 规模不变或变大，同样无法结束
Always Believe 相信子调用能正确解决更小的问题，只考虑当前层如何组合 总想展开完整调用树，难以写清递推关系
Compound Interest 同一子问题不要反复计算 树状递归可能出现指数级重复计算

思考时通常先想Progress，再找Base Case。例如汉诺塔先假设会移动上面n-1个盘，于是当前层只需“移走上层 → 移最大盘 → 移回上层”；顺着规模不断缩小，才得到n=0时什么也不做。阶乘则是先相信factorial(n-1)已算好，再乘n。

常见问题 应如何检查
忘记Base Case 手推n=0或n=1，确认直接返回
有出口却到不了 看每次参数是否严格缩小；n<0时一直做n-1就到不了0
汉诺塔柱子传错 每次递归重新辨认source、target、aux的角色
试图手推所有步骤 只手推小规模，写代码时相信子问题的返回结果

多维状态与缓存键

缓存键必须包含全部决定答案的状态。格子版杨辉三角pascal(n, k)由行n、列k共同决定，仅以n为键会把同一行的不同格子混在一起。

def pascal_cell(n, k, memo=None):
    if memo is None:
        memo = {}
    if k == 0 or k == n:
        return 1
    key = (n, k)
    if key not in memo:
        memo[key] = (pascal_cell(n - 1, k - 1, memo)
                     + pascal_cell(n - 1, k, memo))
    return memo[key]

[n, k] 列表不可哈希，不能作字典键
(n, k) 元组可哈希，能完整表示状态

任务二：整行杨辉三角的递推关系

本节的pascal(n)返回第n行整个列表，从第0行计数；返回单个格子的pascal(n, k)留到后续课程。

行号 返回值
0 [1]
1 [1, 1]
2 [1, 2, 1]
3 [1, 3, 3, 1]
4 [1, 4, 6, 4, 1]
部分 规则
Base Case pascal(0)返回[1]
Progress 先得到上一整行prev = pascal(n-1)
当前行两端 都是1
当前行中间 prev[i] + prev[i+1]
结果长度 第n行有n+1个元素

上一行长度为n，有n-1对相邻元素。想清楚函数返回的是“整行”，才不会把整行问题写成逐个格子重复求值。

坏写法：上一行在循环中反复计算

def pascal_bad(n):
    if n == 0:
        return [1]
    row = [1]
    for i in range(n - 1):
        row.append(pascal_bad(n - 1)[i] + pascal_bad(n - 1)[i + 1])
    row.append(1)
    return row

pascal_bad(3)有两个中间元素，每个元素两次调用pascal_bad(2)，因此仅顶层就调用上一行4次；这些调用又会继续重复计算更小的行。结果虽对，计算却会迅速膨胀。

现象 原因
pascal_bad(16)可能明显变慢 同一上一行在循环内反复递归生成
pascal_bad(1)没有中间元素 仍须在末尾补1，结果才是[1, 1]
加了记忆化后可能变快 重复调用命中缓存，但没有解决写法上不必要的重复请求

好写法：上一行只求一次

def pascal(n):
    if n == 0:
        return [1]
    prev = pascal(n - 1)
    row = [1]
    for i in range(len(prev) - 1):
        row.append(prev[i] + prev[i + 1])
    row.append(1)
    return row
pascal(3)的阶段 结果
递进 3 → 2 → 1 → 0
Base Case pascal(0) → [1]
回归一层 pascal(1) → [1, 1]
再回归 pascal(2) → [1, 2, 1]
最后回归 pascal(3) → [1, 3, 3, 1]

每层只调用一次上一行，调用关系是一条链。第k行拼接花O(k)，从第0行到第n行总时间为O(n^2)；调用栈深O(n)，各层保留的行可能使峰值空间达到O(n^2)。

也可以用列表推导式拼当前行，但上一行仍须先存进变量：

def pascal(n):
    if n == 0:
        return [1]
    prev = pascal(n - 1)
    return [1] + [prev[i] + prev[i + 1]
                  for i in range(len(prev) - 1)] + [1]

若加@lru_cache，键n是可哈希的整数；返回列表本身不妨碍缓存，但不要修改缓存返回的列表。

任务三：迭代实现

递归版是从第n行问到第0行，再逐层回归；迭代版从第0行出发，一行一行生成到第n行。

def pascal_iter(n):
    row = [1]
    for _ in range(n):
        new_row = [1]
        for i in range(len(row) - 1):
            new_row.append(row[i] + row[i + 1])
        new_row.append(1)
        row = new_row
    return row

pascal_iter(4)返回[1, 4, 6, 4, 1]。它与好写法都构造前面各行，时间同为O(n^2)；迭代版只保留当前行和新行，额外空间O(n)，且没有递归调用栈。

实现 上一行的处理 时间 空间 使用时的判断
坏写法 每拼一个中间项就重新递归 重复计算严重 调用数膨胀 避免
好写法 递归一次，存入prev O(n^2) 最坏O(n^2) 便于理解递推
迭代 从第0行逐行更新row O(n^2) O(n) 大规模时更稳妥

全排列：选择、递归、撤销

PTA W6 · 6D01《密码全排列》。给定一个无重复小写字母字符串，长度为\(1\)到\(8\)，用递归生成所有排列，按字典序输出。

  • 接口：list_permutations(s)；输入字符串，返回按字典序排列的字符串列表，函数内不打印。
  • 样例：输入cab，返回['abc','acb','bac','bca','cab','cba']；裁判把每个字符串单独打印一行。
  • 每个字符在一种排列中恰好用一次，不能遗漏或重复使用。

输入字符互不重复；先排序，按这个顺序尝试每个尚未使用的字符，输出自然为字典序。

def list_permutations(s):
    chars = sorted(s)
    used = [False] * len(chars)
    result = []

    def build(path):
        if len(path) == len(chars):
            result.append(''.join(path))
            return
        for i, ch in enumerate(chars):
            if used[i]:
                continue
            used[i] = True
            path.append(ch)
            build(path)
            path.pop()
            used[i] = False

    build([])
    return result

一次分支结束必须撤销path和used，否则后续分支受污染。保存字符串快照不会与路径共享；若结果需要存列表，应保存path[:]。共有\(n!\)个结果，生成并保存它们至少需要\(O(n\cdot n!)\)时间与结果空间。

嵌套列表深度

PTA W6 · 6D02《货箱层深》。用嵌套列表表示货箱，元素只有整数或子列表，递归求最大嵌套层数。

  • 接口：max_depth(xs)，返回整数深度。
  • 定义：整数深度为\(0\)，空列表深度为\(1\)，列表深度为最深子项深度加\(1\)。
  • 样例：[1,[2,3],[[4],5]]返回3；[]返回1，[1,2]返回1。

非列表深度为\(0\)；空列表深度为\(1\)；非空列表比最深子项多一层。注意[[]]深度为\(2\)，不是\(1\)。

def max_depth(xs):
    if not isinstance(xs, list):
        return 0
    deepest = 0
    for item in xs:
        deepest = max(deepest, max_depth(item))
    return 1 + deepest

减治与分治

递归是思考和实现子问题的方式；减治与分治描述的是子问题怎样产生、怎样得到原问题的答案。

方法 子问题 例子
减治 只做缩小后的一个问题 二分查找比较中点后舍弃另一半
分治 多个子问题都要做，再处理它们之间的关系 归并排序分别排好两半，再合并

递归二分查找

二分查找前提是列表已排序。

def binary_search_rec(lst, target, left=0, right=None):
    if right is None:
        right = len(lst) - 1
    if left > right:
        return -1
    mid = left + (right - left) // 2
    if lst[mid] == target:
        return mid
    if lst[mid] < target:
        return binary_search_rec(lst, target, mid + 1, right)
    return binary_search_rec(lst, target, left, mid - 1)

e.g. 在[1,3,5,7,9]中找7：先看下标2的5，缩到右半区间[3,4]；再看下标3，返回3。每次减半，时间为\(O(\log n)\)。递归调用后的结果直接返回，所以这是尾递归；递归栈为\(O(\log n)\)。

不要为了“切一半”反复写列表切片：lst[:mid]会创建并复制新列表，还要重新换算原列表下标；保留原列表、只改边界更直接。若每层切片，全部复制成本可达\(O(n)\)。

归并排序：先分，再合

只排好左半，整表还不一定有序。归并排序先把列表拆到长度至多为1，回归时相信左右两半都已排好，再用两个指针合并：

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result

def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

merge([1,3,5],[2,4,6])依次取1,2,3,4,5，左边耗尽后还须追加右边剩余的[6]。漏掉extend会丢元素。相等时用<=先取左边，这样相等元素的原有顺序不变，归并是稳定排序。

递归树深度约为\(\log_2 n\)；每层总共合并\(n\)个元素，所以时间\(O(n\log n)\)。结果缓冲需要\(O(n)\)额外空间；这里的arr[:mid]、arr[mid:]也会复制。下标区间版可省去分割切片，但合并仍需要缓冲。

自底向上的纯循环版

对于归并这种非线性递归，其转化为循环的方式有一点不一样。 可以从长度为\(1\)的有序段开始，两两合并成长度约为\(2,4,8,\ldots\)的有序段。每轮用上面的merge，没有递归调用：

def merge_sort_iter(arr):
    result = arr[:]
    width = 1
    while width < len(result):
        merged = []
        for start in range(0, len(result), 2 * width):
            left = result[start:start + width]
            right = result[start + width:start + 2 * width]
            merged.extend(merge(left, right))
        result = merged
        width *= 2
    return result

两版时间都是\(O(n\log n)\)；这个循环版仍通过切片和merged构造新列表，额外空间为\(O(n)\)，只是省掉了递归调用栈。

最大子串和

连续子串的最大和可能完全在左边、完全在右边，或跨过中点。前两类由递归给出；第三类必须在当前层计算：从mid-1向左找最大后缀，从mid向右找最大前缀，两者相加。

def max_crossing(arr, lo, mid, hi):
    total = best_left = arr[mid - 1]
    for i in range(mid - 2, lo - 1, -1):
        total += arr[i]
        best_left = max(best_left, total)
    total = best_right = arr[mid]
    for j in range(mid + 1, hi):
        total += arr[j]
        best_right = max(best_right, total)
    return best_left + best_right

def max_subarray(arr, lo=0, hi=None):
    if hi is None:
        hi = len(arr)
    if hi <= lo:
        raise ValueError("需要非空区间")
    if hi - lo == 1:
        return arr[lo]
    mid = (lo + hi) // 2
    return max(
        max_subarray(arr, lo, mid),
        max_subarray(arr, mid, hi),
        max_crossing(arr, lo, mid, hi),
    )

例如[-2,3,-1,4]切成[-2,3] | [-1,4]，左、右各自最优是\(3\)和\(4\)；跨中点为左后缀\(3\)加右前缀\(-1+4=3\)，得到\(6\)。这一写法求非空子串，单元素就是Base Case；空列表要另行约定。每层扫描合计\(O(n)\)，时间\(O(n\log n)\)。

Kadane算法

如果不必用分治，也可以从左到右扫描。到元素\(a_i\)时，以它结尾的最大子段和要么从\(a_i\)重新开始，要么接在前一个最优后缀后面：

\[ E_i=\max(a_i,E_{i-1}+a_i),\qquad M_i=\max(M_{i-1},E_i) \]

其中\(E_i\)是以\(i\)结尾的最大子串和，\(M_i\)是前\(i\)个位置中出现过的最大值。

def max_subarray_linear(arr):
    current = best = arr[0]
    for i in range(1, len(arr)):
        current = max(arr[i], current + arr[i])
        best = max(best, current)
    return best

对[-2,3,-1,4]，current依次为\(-2,3,2,6\)，最终返回\(6\)。用首元素初始化，而非初始化为\(0\)，才能正确处理全负数列表。只扫描一次，时间\(O(n)\)，额外空间\(O(1)\)。

前缀和思路

设\(P_0=0\)，\(P_j\)是前\(j\)个元素的和。以第\(j\)个元素结尾的子串和为\(P_j-P_i\)（\(i<j\)）；要让它最大，就减去此前最小的\(P_i\)。

def max_sum(lst):
    min_prefix = 0
    prefix = 0
    best = lst[0]
    for x in lst:
        prefix += x
        best = max(best, prefix - min_prefix)
        min_prefix = min(min_prefix, prefix)
    return best

min_prefix初值为\(P_0=0\)，所以子串可以从第一个元素开始。先用旧的min_prefix更新答案，再纳入当前前缀，才能保证\(i<j\)、子段非空；如果反过来，当前前缀可以减去自己，得到空子段的和\(0\)，全负数时就会出错。这与Kadane是同一个\(O(n)\)问题的两种视角，额外空间都是\(O(1)\)。

逆序对：合并同时计数

若下标\(i<j\)且\(a_i>a_j\)，就有一对逆序。递归分别统计左右内部的c1,c2；合并时若当前右元素小于左元素，左边尚未取走的元素都与它构成逆序，一次增加len(left)-i。

def merge_count(left, right):
    result = []
    i = j = count = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            count += len(left) - i
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result, count

def inversions(arr):
    if len(arr) <= 1:
        return arr, 0
    mid = len(arr) // 2
    left, c1 = inversions(arr[:mid])
    right, c2 = inversions(arr[mid:])
    merged, c3 = merge_count(left, right)
    return merged, c1 + c2 + c3

[3,1,4,2]有\((3,1)\)、\((4,2)\)和\((3,2)\)，共\(3\)对。相等时取左边，不计逆序；只返回跨半的\(c_3\)则会漏掉左右内部的\(c_1+c_2\)。时间仍是\(O(n\log n)\)。return result, count实际返回元组，调用处可拆成两个变量。

key、lambda与高阶函数

key接收一个函数，先把每个元素映射成比较用的值；它不改变结果里保存的原元素。

max([-7, 4, 2], key=abs)            # -7，按绝对值比较
sorted(nodes, key=lambda x: x.freq) # 按 freq 排序

已有函数可直接传函数名；只用一次的短规则可用lambda；规则复杂就先用def定义。把函数作为参数传入，属于高阶函数的用法。

杨辉三角：两个递归调用也未必是分治

W6的pascal(n)返回整行；这里的pascal(n,k)只求第\(n\)行第\(k\)个数。两侧为1，中间等于上一行相邻两项之和：

def pascal(n, k, memo=None):
    if not 0 <= k <= n:
        raise ValueError("需要 0 <= k <= n")
    if memo is None:
        memo = {}
    if k == 0 or k == n:
        return 1
    key = (n, k)
    if key not in memo:
        memo[key] = pascal(n - 1, k - 1, memo) + pascal(n - 1, k, memo)
    return memo[key]

\(\operatorname{pascal}(4,2)=6\)。左右分支会重复遇到同一状态，如pascal(2,1)，所以用元组(n,k)作缓存键。这里不是折半处理两段，而是规模每次减\(1\)的重叠子问题；不能因为有两次递归调用就把它当成归并式分治。

分区与递归规模的检查

简洁版快排必须先取出基准，再用arr[1:]分区；若把基准也放回某个子列表，规模可能根本没有缩小。右边用>= pivot保留相等元素。首元素作基准遇到已排序列表时，每轮只减少一个元素，最坏时间\(O(n^2)\)、递归深度\(O(n)\)；随机选基准能减少固定输入造成的退化风险，但不保证每次都平衡。重复元素很多时，用<、==、>三路分区，让相等项不再参与递归。

归并与快排：工作在不同阶段

手推merge([1,3],[2,4])：依次取1,2,3后，左边已空；必须追加剩余的4。归并是先排好两半，再合并；快排则是先按基准分区，再递归排两侧。

归并排序 快速排序
当前层重点 合并两个已排序的列表 选pivot，把小于它的放左边，其余放右边
递归后 做merge 直接拼接两侧和基准
容易出错 忘记追加剩余段 基准又进入子问题，或漏掉相等元素

简洁快速排序

以首元素为pivot。arr[1:]排除基准；左边取< pivot，右边取>= pivot，相等元素才不会丢：

def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    left = [x for x in arr[1:] if x < pivot]
    right = [x for x in arr[1:] if x >= pivot]
    return quick_sort(left) + [pivot] + quick_sort(right)

[3,1,4,1,5,9,2,6]以3为基准时，左边是[1,1,2]，右边是[4,5,9,6]；右边仍需递归排序。验证结果时除了看是否有序，还要确认元素和出现次数都没有变化。

首元素基准的退化与三路分区

对已排序的\([1,2,\ldots,n]\)，首元素每次都是最小值：左边为空，右边只少一个元素。于是递归深度从平均的\(O(\log n)\)变成\(O(n)\)，时间最坏\(O(n^2)\)，Python中还可能触及递归深度限制。随机选基准能降低固定坏输入的影响，但不能保证次次平衡。

重复值很多时，把== pivot单独放在中间，相等项无需再递归：

def quick_sort_3way(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[0]
    less = [x for x in arr if x < pivot]
    equal = [x for x in arr if x == pivot]
    greater = [x for x in arr if x > pivot]
    return quick_sort_3way(less) + equal + quick_sort_3way(greater)

例如[8,3,5,1,7,2,9,4]以5为基准，分为[3,1,2,4] | 5 | [8,7,9]。简洁版快排的列表推导式和拼接会创建新列表；它只是为了把分区思路写清楚，不等同于常见的原地快排。归并时间稳定在\(O(n\log n)\)；快排平均\(O(n\log n)\)、最坏\(O(n^2)\)。

检查分治代码，重点看三处：Base Case能否结束；子问题是否真的缩小；当前层有没有漏掉必须处理的部分——归并的剩余段、最大子段和的跨中点情况、快排的相等元素与基准排除。

两次递归二分计频次

PTA W7 · 7C01《频段重复次数》。给定允许重复的升序整数列表和目标值，用两次递归二分求目标值出现次数；不存在则返回\(0\)。

  • 接口：count_freq(arr, target)，返回次数，不是下标。
  • 样例：count_freq([1,2,2,2,3,4], 2)返回3；目标为5时返回0。
  • 题目要求分别找左右边界，不能找到一次后直接返回，也不能用线性count代替。

统一使用半开区间[lo,hi)。第一次找首个不小于目标的位置，第二次找首个大于目标的位置，二者之差就是出现次数；不存在时两个边界相同。

def count_freq(arr, target):
    def bound(lo, hi, upper):
        if lo >= hi:
            return lo
        mid = (lo + hi) // 2
        if arr[mid] < target or (upper and arr[mid] == target):
            return bound(mid + 1, hi, upper)
        return bound(lo, mid, upper)
    return bound(0, len(arr), True) - bound(0, len(arr), False)

两次二分仍为\(O(\log n)\)。闭区间与半开区间都可以，不能混用right=len(arr)-1、lo>=hi等来自不同模板的边界。

  • 样例：f=lambda x: x**2-2、初值1.0,2.0、精度1e-6，返回约\(1.41421356\)，裁判保留三位小数输出1.414。
  • 下方secant_checked是增加失败检查的复习版；按PTA接口使用时将函数名改为secant即可。

题面要求\(|f(x)|<\varepsilon\)。下面按此规格停止；导数差接近零或迭代失败应显式报告，不能假装返回了根。

def secant_checked(f, x0, x1, eps, max_iter=1000):
    f0, f1 = f(x0), f(x1)
    for _ in range(max_iter):
        if abs(f1) < eps:
            return x1
        if abs(f1 - f0) < 1e-15:
            raise ValueError("弦截法分母过小")
        x2 = x1 - f1 * (x1 - x0) / (f1 - f0)
        x0, x1 = x1, x2
        f0, f1 = f1, f(x1)
    raise ValueError("迭代未收敛")

数组与链表

数据结构是组织和存取数据的方式。选择结构时，先看需要频繁执行什么操作：按下标访问、在中间插删，还是按一定顺序取出。

传统数组通常存放同类型元素，长度固定；Python的list长度可变、可以混合类型。Python列表内部连续存放的是对象引用，对象本身不一定连续。

链表的每个结点保存数据和指向下一个结点的引用，结点不必连续存放。它不必移动后面的元素，但按位置查找时需要从头沿引用查找。

操作 数组 / Python list 单向链表
按下标访问 \(O(1)\) \(O(n)\)
头部插入 \(O(n)\)，后续元素移动 \(O(1)\)
已知位置插入、删除 最坏\(O(n)\) 改链接\(O(1)\)

链表删除需要已经持有待删结点的前驱结点；若先按值或下标寻找位置，查找仍需\(O(n)\)。链表结点分散，也可能不如连续存储有利于缓存。

Python有array等专门的数组工具；日常通用序列通常使用list。

栈：后进先出

栈（Stack）遵循LIFO (Last in First Out)：最后入栈的元素最先出栈。主要操作是push入栈、pop出栈、peek查看栈顶。撤销操作和函数调用栈都符合这一顺序。

strokes = []
strokes.append("圆形")
strokes.append("直线")
strokes.append("矩形")
strokes.pop()          # "矩形"
strokes[-1]            # "直线"，查看但不删除

用list尾部append和pop()实现栈，两者均摊\(O(1)\)；空列表执行pop()或stack[-1]会抛出IndexError。

括号匹配

右括号必须与最近一个尚未匹配的左括号配对，所以使用栈。下面约定输入只含六种括号：

def is_valid(s):
    stack = []
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        else:
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
    return not stack

{[()]}依次压左括号入栈，再依次匹配出栈，最后栈空，返回True。要检查三种错误：右括号到来时栈空、栈顶类型不匹配、读完后栈里仍有左括号。not stack or ...利用逻辑短路，先避免访问空栈。

每个字符最多入栈和出栈一次，时间\(O(n)\)；最坏情况下栈保存\(n\)个左括号，空间\(O(n)\)。

队列：先进先出

队列（Queue）遵循FIFO (First in First Out)：队尾入队，队首出队。打印任务、餐厅订单和广度优先搜索(BFS)都要求先来先处理。

from collections import deque

orders = deque()
orders.append("A")         # 队尾入队
orders.append("B")
first = orders.popleft()  # 队头出队，得到 "A"

list.pop(0)虽然也能取队头，但删除后其余引用要前移，单次\(O(n)\)；连续取空\(n\)个元素总共需要\(O(n^2)\)。deque.popleft()从左端取出，单次\(O(1)\)，连续取空为\(O(n)\)。

deque是双端队列，从collections导入。两端追加与弹出通常都是\(O(1)\)；它适合队列，但中间位置的随机访问是\(O(n)\)，不能代替列表频繁按下标访问。

deque(iterable) 用可迭代对象初始化 新deque
append(x) / appendleft(x) 右端 / 左端加入 None
pop() / popleft() 右端 / 左端移除并返回 空队列抛IndexError
extend(xs) / extendleft(xs) 逐个加入右端 / 左端 extendleft会使加入部分的顺序反转
rotate(k) 循环移动 正数向右、负数向左；原地修改
clear() 清空 None
d[0] / d[-1] 查看两端 不删除；空队列不能取下标 
from collections import deque

d = deque([1, 2, 3])
d.extendleft([4, 5])  # deque([5, 4, 1, 2, 3])
d.rotate(1)           # deque([3, 5, 4, 1, 2])

recent = deque(maxlen=3)
recent.extend([1, 2, 3, 4])  # deque([2, 3, 4])

设置maxlen后，append或appendleft在已满时会从另一端丢掉元素；这是有界缓存的行为，使用前要确认是否允许丢失旧数据。
